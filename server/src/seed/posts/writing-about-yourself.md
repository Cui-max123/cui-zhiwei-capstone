# Shipping a portfolio when you hate writing about yourself

I can write a thousand words about database indexes. Ask me to write two sentences about my own strengths and I will stare at the cursor until the laptop sleeps.

This is the portfolio paradox: the people who are best at building things are often the least comfortable selling them. The site is supposed to be a solution. For a long time it was another unfinished project.

## Start with evidence, not adjectives

"Passionate developer" is not evidence. "Built a course planner that two classmates used during registration" is evidence. The second sentence is easier to write because it is a fact, and it is more useful because a reader can picture it.

I made a list of things I had actually finished, however small:

- a CLI that cleans CSV files;
- a reading-list PWA I use every week;
- this API, with tests that fail when I break auth;
- a bug fix that took two days and taught me how `populate` works.

Then I wrote one paragraph about each. The "About me" page became a summary of the list instead of a personality quiz.

## Borrow a structure

Writing from a blank page is hard. Writing into a shape is easier. I use four prompts for every project:

1. **The problem.** What was annoying, missing or broken?
2. **The build.** What did I actually make?
3. **The hard part.** What did I get wrong first?
4. **The result.** What works now, and what would I change?

The hard part is the most important one. A portfolio that only shows successes reads like a brochure. A portfolio that explains a wrong turn reads like a person.

## Make the site easy to update

A portfolio you are afraid to edit will go stale. The admin dashboard exists because I wanted to add a project without opening the code, remembering how the build works, and redeploying. It is a small thing, but it lowered the cost of telling the truth about my work.

## The bar is lower than you think

Nobody is expecting a memoir. A visitor wants to know three things: what you build, whether you can finish, and how to contact you. That is a homepage, a project list and a form. Everything else is craft.

If you are stuck, publish the three things. Then improve the typography.
